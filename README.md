# Weather-Station
ESP32 Weather Station
 - Built a connected weather station that combines locally measured environmental data with weather information retrieved from the internet.
 - Used an SHT31 sensor over I²C to measure indoor temperature and humidity.
 - Connected the ESP32-C3 to Wi-Fi and retrieved current conditions and forecast information from a weather API.
 - Used NTP to maintain accurate time and track when weather information was last refreshed.
 - Displayed multiple categories of weather information across different screens on the display, including indoor conditions and outdoor weather data.
 - Managed data coming from sources that refresh at different intervals while keeping the displayed information current. Your resume currently captures the core architecture as ESP32-C3 + SHT31/I²C + Wi-Fi/Web API + NTP.
